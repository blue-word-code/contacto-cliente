    Cobertura de notas de voz

    Toca una fila para ver sus clientes sin nota de voz.

    Cargar datos

    1. Importar clientes desde Excel o CSV

    La primera fila debe tener los títulos. Se reconocen: Código, Nombre, Dirección, Sector/Zona, Ruta, Vendedor/Chofer y Teléfono. Si un código ya existe, se actualizan sus datos; no se borra nada.

    2. Subir notas de voz

    Elige uno o varios audios. Si el nombre del archivo lleva el código del cliente (por ejemplo C00123.mp3 o 00123 Juan Perez.ogg), se asocian solos. Recomendado hasta 200 archivos por vez; para miles usa la opción 3.

    3. Sincronizar la carpeta de Drive (miles de audios)

    1. Copia los audios directamente dentro de la carpeta de notas de voz en Google Drive, sin subcarpetas (con Google Drive para escritorio puedes arrastrar carpetas enteras).
    2. Pulsa Sincronizar. La app revisa cada archivo y lo asocia al cliente cuyo código aparece en el nombre.
    3. Los audios que no se puedan asociar aparecen abajo para asignarlos a mano.
